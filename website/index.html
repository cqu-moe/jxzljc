开始安装

Tampermonkey 用户脚本 · 免费开源

从安装油猴开始

已安装油猴，可以从第二步开始。

  1. 01

    安装油猴 Tampermonkey

    用电脑浏览器打开 Tampermonkey 官网，选择你正在使用的浏览器，进入对应的扩展商店。点击“添加”或“获取”，确认安装，然后在浏览器的扩展菜单里找到油猴并保持启用。

    前往油猴官网
    Chrome / Edge 提示需要执行用户脚本的权限？

    打开浏览器的扩展管理页面，找到 Tampermonkey。在支持的浏览器版本中，打开详情里的“允许用户脚本”；如果没有这个选项，按油猴官方说明启用“开发者模式”。完成后刷新评教页面。

    查看油猴官方图文说明
  2. 02

    安装「重庆大学快速评教」脚本

    打开 Greasy Fork 页面，点击“安装此脚本”，再在油猴弹出的确认页点击“安装”。也可以用 GitHub 安装链接，直接打开油猴确认页。两种来源选一种即可。

    从 Greasy Fork 安装从 GitHub 安装

    安装后，在油猴“管理面板”里确认「重庆大学快速评教」已启用。如果打开的是代码文本，先检查油猴是否安装并启用。

  3. 03

    打开学校评教系统

    正常登录学校的学生评教系统，进入学生评教页面。右下角出现「快速评教」按钮，说明脚本已经运行。若刚安装完，刷新一次页面；已有单门评价窗口时，先关闭它以保存草稿。

    打开学生评教系统

    仅校园网可访问 · HTTP 站点。账号登录只在学校系统完成，这个官网不需要你的账号或密码。

  4. 04

    填写设置，核对后再提交

    点击「快速评教」，选择满意度和综合评分，按需填写评语。点击“下一步”，勾选课程并逐门核对；需要调整时展开课程，修改该门课的评分或评语。确认无误后，点击脚本中的“开始刷课”提交。

    请按真实感受评价，一次只在一个标签页运行。停止操作会等当前请求核实后，再停止后续提交。

常见问题

它会自动给所有课程打满分吗？

不会。脚本不预选评价内容，满意度和综合评分都由你选择。统一设置只补空白；已有草稿会保留，预览时也可以逐门修改。

需要把账号或密码交给这个工具吗？

不需要。脚本使用你在学校评教系统的当前登录状态，只访问学校站点的同源接口，不收集账号，也不向第三方上传评价。

已经写过的草稿会被覆盖吗？

生成预览时优先保留已有内容，仅补空白。你在预览里修改的内容只用于本次提交，不会改写学校的本地草稿。若预览后学校草稿发生变化，旧的提交计划会停止使用。

没有出现「快速评教」按钮怎么办？

先检查油猴和脚本都已启用，再按第一步的说明检查用户脚本执行权限。登录并进入学生评教页面后刷新一次。脚本只在匹配的学生评教页面运行，不会出现在学校的所有网页上。

支持哪些课程？可以在手机上用吗？

脚本只处理当前学期尚未评教的条目。目前支持已核实的 A–E 五档选择题，检查过理论课和实验课；遇到未知题型会停止。建议使用电脑浏览器。界面有小屏布局，但手机浏览器的扩展支持及真实手机使用尚未完整验证。

提交失败、停止或刷新后，会发生什么？

失败或结果不明确时会停止，不会自动重试。停止后续提交会等待当前请求核实，再停止下一条。刷新不会继续提交，也不会保留本次临时设置；请先在学校页面核实结果，再决定是否重新预览。已经提交的评价仍受学校系统的修改规则约束。

这是学校官方提供的工具吗？

这是 CQU Moe 提供的开源辅助工具，并非学校官方产品。评价内容由你确认，最终结果以学校评教系统为准。官网展示的是示例数据，不包含真实课程或教师资料。

脚本怎么更新，遇到问题去哪里反馈？

在油猴中启用更新检查即可。Greasy Fork 安装由 Greasy Fork 提供更新，GitHub 安装从仓库 main 分支更新；无需同时安装两份。
