# 设计接入与验收

使用 CQU Design **theme 1.1.0**。参考该版本的 `START-HERE.md`、`DESIGN.md`、`docs/consumption.md`、布局／组件／状态／动效规范，以及账号设置页的分组方式。

## 接入方式

脚本是原生 JavaScript 与 Shadow DOM，按设计系统允许的「非 React 系统仅接入 theme」路径实现；继续使用原生 dialog、表单控件和站点接口。未引入 React、UI 组件包、Toast 或图标依赖，未复制共享组件或覆盖 `.ds-*` 规则。

`.design/` 保存本地主题包，开发时由 `scripts/design.mjs` 读取公开的 `@cqu-moe/theme/styles.css`。`npm run build` 只把 `:root` 选择器转换为 shadow host 对应的 `:host` 选择器，并嵌入脚本标记区；设计变量保持原样。这是主题文件同步，不需要打包器或运行时网络依赖。学校页面不受主题 CSS 影响。

界面自动跟随系统深浅色，未增加手动主题偏好或存储键。无列表／弹窗入场动画，键盘和减少动态效果模式同样即时显示。颜色、字号、间距、圆角与阴影使用共享语义变量；44px 触屏尺寸、16px 输入下限和视口断点为浏览器布局约束。

固定头尾、滚动内容区用于保留长清单中的停止／恢复入口。预览后定位到清单；提交期间突出停止动作，结束后焦点返回刷新按钮。v0.3.0 使用原生 details/summary 展开课程，复选框作为独立控件放在展开控件外，避免嵌套点击冲突；CSS 仅绘制展开指示。收起时省略过长名称，展开可读完整名称和教师。选择与编辑共用提交锁；校验失败会展开课程并聚焦错误字段。

## 自动检查

```sh
npm ci
npm run build
npm run check
npm run check:design
npm test
```

`check:design` 是适用于单文件脚本的有限检查：保证内嵌 CSS 与本地主题包一致、业务样式不使用原始颜色／全属性过渡、引用的主题变量存在。它不等同于 React UI 包的完整消费检查器，也不证明视觉、可访问性或真实接口正确；需结合下面的页面检查。
